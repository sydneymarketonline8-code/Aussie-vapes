# Australian Vape E-commerce Scaffold

This starter scaffold is built for an Australian vape e-commerce website focused on SEO, conversions, and fast performance.

## Included structure

- `index.html` — homepage with category navigation and conversion-first messaging
- `category/` — niche-focused landing pages for top vape segments
- `product/` — sample conversion-focused product detail pages
- `assets/css/styles.css` — lightweight responsive styling
- `assets/js/main.js` — interactive navigation behavior and scalability hooks
- `robots.txt` — SEO guidance for crawlers
- `sitemap.xml` — sample sitemap for search engines

## Getting started

1. Open `index.html` in a browser for a quick preview.
2. Replace placeholder content with real product details, pricing, and branding.
3. Add more category and product pages to match your target keyword strategy.

## Recommended next steps

- Add Australian payment and shipping messaging prominently.
- Build content for regulatory and buyer intent pages (e.g. `vape-laws-australia.html`, `vape-compare.html`).
- Implement age verification and checkout flow in the next stage.
